## Sheffield Park 3 공개 실영상 9장

입력과 재현 명령: [선정 9장 안내](datasets/sheffield_park_3/selected9/README.md). 기준 5번은 `DJI_0075.JPG`입니다. GPS에서 유도한 상대 위치와 짐벌 yaw를 사용했으며, Pixhawk 로그는 아닙니다. 이 입력의 공간 번호와 배열 순서는 원본 비행의 촬영 시간 순서와 다릅니다.

SIFT, 원본 4000×3000 px, 특징점 처리의 긴 변 2000 px, CPU 실행 결과:

| 항목 | 결과 |
|---|---:|
| 지도 크기 | 2315×2617 px |
| 채택한 이웃 연결 | 20/20 |
| 독립 그래프 순환 수 | 12 |
| 연결별 RANSAC 인라이어 수 | 187~1141 |
| 연결별 중앙 잔차의 중앙값 | 1.99 px |
| 연결별 중앙 잔차의 최댓값 | 3.51 px (기준 4 px) |

잔차는 기준 이미지 원본 픽셀 단위입니다. 중첩률은 정합된 평면 촬영 범위의 교집합 면적을 두 범위 중 큰 면적으로 나눈 추정값입니다. 정해진 비행 간격으로 계산하는 선형 중첩률과는 정의가 다릅니다.

결과: `runs/sheffield_selected9_sift_west/`의 `map.png`, `overview.png`, `transforms.json`, `diagnostics.json`, `validation_summary.json`. 지도↔로컬 좌표 왕복 변환과 기준 원점도 확인했습니다. 지면 경계는 대체로 정합되지만 나무와 건물에는 시차로 인한 잔상이 보입니다. GPS·명목 촬영 높이·35mm 환산 초점거리로 정한 축척은 실측 검증하지 않았습니다.

처음 시도한 더 넓은 9장 조합은 두 연결의 전체 정합 잔차가 기준을 넘어 실패했습니다. 진단은 `runs/sheffield_selected9_sift/diagnostics.json`에 보존했습니다. 이후 서쪽 구간의 9장을 선정해 **기존 4 px 품질 기준을 바꾸지 않고** 통과했습니다. 이번 실영상 입력에서는 SIFT만 검증했으며, 전체 데이터셋이나 다른 9장 조합의 성공을 의미하지 않습니다.

## 자동 테스트 범위

- SIFT 전체 처리 + 메타데이터 보간 + 특징점용 영상 축소
- ORB 전체 처리 + 메타데이터 없는 격자 초기화
- 합성 정답의 전체 지점 RMSE < 0.04m, 최대 오차 < 0.12m
- 5번 원점 고정, 저장된 행렬의 왕복 변환, NED 세션 식별자 불일치 거절
- NED N/E 축, 회전된 격자 방위, 카메라 장착 yaw offset
- 주점이 이미지 중심과 다른 경우의 원점, 원본 왜곡 픽셀의 보정 후 변환
- yaw ±π 경계 보간, 비동기 필드, 큰 시각 공백, 시계 리셋/유효하지 않은 메타데이터
- 메타데이터 방위 부족 시 명시적 격자 fallback, NED z를 AGL로 오해하지 않음
- 검은 유효 픽셀을 포함한 블렌딩과 중첩 수
- 과대 캔버스와 영상 내부 homography 무한대 투영 거절
- 특징점이 없는 한 장 때문에 연결이 끊기면 진단만 저장하고 지도 생성 실패
- 잘못된 이미지 순서/중복/누락/장수 거절, 기존 결과 덮어쓰기 거절

## 아직 필요한 실측 검증

프로젝트 자체 카메라의 이미지 9장과 노출 시각, 같은 EKF 기준의 위치/yaw, 카메라 내부 보정 및 장착 방향을 준비해 실행해야 합니다. 매칭 잔차와 별도로 지상 기준점/거리 및 지도상의 드론 위치 오차를 측정해야 합니다. 다양한 지형의 높이 차, 기체 기울기, 반복 무늬, 이동체와 노출 변화에서의 실패율도 아직 측정하지 않았습니다.
