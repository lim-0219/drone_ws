# 외부 자료와 라이브러리

출처: https://github.com/pierotofy/drone_dataset_sheffield_park_3

Copyright (c) 2017, Piero Toffanin. 원본 저장소에서 제공한 BSD 2-Clause 라이선스 전문을 `datasets/sheffield_park_3/selected9/LICENSE`에 동봉했습니다. 사진 재배포 시 해당 고지와 조건을 유지하세요. 선정한 JPG 9장은 원본 바이트를 보존했으며 출처 URL과 SHA-256을 `selected_images_sha256.json`에 기록했습니다.

## Python 라이브러리

NumPy, SciPy, OpenCV(opencv-python-headless), pytest 및 설치 도구는 각 프로젝트의 라이선스를 따릅니다. 이 배포본에는 해당 라이브러리 바이너리를 포함하지 않습니다. 설치할 때 Python 패키지 저장소에서 내려받습니다. 고정 버전은 `requirements.txt`, `requirements-dev.txt`를 참고하세요.

이 사진 라이선스를 본 프로젝트의 전체 코드에 적용한다는 의미는 아닙니다.
